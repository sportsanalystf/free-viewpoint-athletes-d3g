# Mid-term slides

The deck is a Claude Slides artifact (private until shared from its Share menu; it exports to PowerPoint or PDF).
This folder is a backup of its source: `deck.json` (slide order, sections, fonts) and one HTML file per slide in
`slides/`, with speaker notes in each slide's `<aside>`. Images and videos in the slides are stored with the
artifact (`/_blob/...` links), so these files are a text backup, not a standalone deck.
