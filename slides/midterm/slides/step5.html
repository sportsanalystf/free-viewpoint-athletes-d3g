B · Build the 4D model · step 5

Fit the first frame

WHAT IT DOES

Fits frame 0 like normal 3D Gaussian Splatting: 10k iterations, image loss plus mask loss. Gaussians are split, cloned and pruned as needed.

WHY

Every later frame starts from this one, so it sets the colours and shapes for the whole clip.

WHAT WE GOT

Before training it is a grey blur. After 500 iterations: 27.9 dB on a held-out camera. Gaussians grow 194k → about 365k.

Held-out view during training: start → 500 → 1k → 3k → 10k iterations
